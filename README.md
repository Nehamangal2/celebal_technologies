# Celebal Technologies Data Science Internship

During my internship at Celebal Technologies, I designed and implemented an end-to-end Machine Learning pipeline on sales and price datasets. The project covered the complete data science workflow, including data preprocessing, exploratory data analysis (EDA), feature engineering, regression modeling, hyperparameter tuning, model evaluation, and time series forecasting.

## Key Highlights

* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Regression Model Development
* Hyperparameter Optimization
* Model Evaluation and Performance Analysis
* Time Series Forecasting
* End-to-End ML Pipeline Implementation

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook
